# What this is

A Cursor agent you ask about travel. Not an app. Not a planner screen.

You type a question in Cursor. The agent reads `data/who-i-am.md`, `data/taste.json`, `data/taste-vector.json`, and `data/history.json`. It filters on the ask (area, open, family), scores the restaurant, ranks by that score, answers with the pick **and the scores**, then asks for feedback.

No booking. No itinerary builder. No paid APIs outside Cursor.
